📌 Overview
TradeIt is a dual-interface application (Java desktop + Symfony web) that facilitates item trading among users. It allows users to add products, browse and trade items, view event announcements, and manage their profiles in a secure and user-friendly environment. This system is designed to promote sustainability by encouraging the reuse and exchange of goods.

🔧 JavaFX Desktop Client: For users who prefer a lightweight local interface.

🌐 Symfony Web Application: For online access, admin management, and full platform visibility.

🧩 Features

📢 Announcement system for trade events or promotions
